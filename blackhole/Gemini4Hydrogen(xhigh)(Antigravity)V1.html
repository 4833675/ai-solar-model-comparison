已实现的精确广义相对论算法
• 光线追踪核心：无质量测地线在 WebGL2 片元着色器中采用四阶龙格–库塔 (RK4) 逐像素积分。a = 0 时使用史瓦西精确等价轨道方程 u″ + u = 3u²；a > 0 时使用出射正则化等价坐标（A = −a）的 Kerr–Schild 哈密顿方程组，消除视界坐标奇点与发散，并用静态观察者四标架完成出发变换。
• 吸积盘辐射模型：采用 Page–Thorne (1974) / Novikov–Thorne 相对论薄盘通量剖面（diskModel = 'NT'），包含参考系拖曳下的全部引力红移与多普勒集束因子 g，并按观测温度 g·T(r) 映射 CIE 1931 线性 sRGB 黑体色表。
• 测试粒子透镜：轨道实验室与热斑均直接注入主光线追踪积分循环（particlesLensed = true），因此在黑洞背后运动时会自然形成爱因斯坦弧与次级像。
模型近似与非物理提示（6.5 节诚实性声明）
1. 色温标度 T_max 为人为显示参数：真实超大质量黑洞（如 Sgr A*、M87*）的辐射峰值并不位于可见光波段；且其周围吸积流为光学薄、几何厚的磁化等离子体流（RIAF/MAD），而非本模型假设的几何薄、光学厚 Keplerian 盘。
2. 冻结时间近似（快速光近似）：单帧积分期间假设吸积盘与测试粒子保持静止，忽略光子穿过黑洞附近时的光行时差（参见 3.9 节）。
3. 程序化星空：背景恒星与银河带均由三维立方体网格哈希与噪声现场生成，并非真实天体星表。
4. 静止观察者相机：标准相机处于静止观察者标架；渲染未叠加速度光行差（仅“跳进视界”自由落体拓展模式显式计算坠落洛伦兹光行差与多普勒偏移），且像素亮度采用无穷远参照系红移 g（未额外乘相机当地微弱蓝移因子 1/√(1 − f_cam)）。
5. 非物理开关说明：关闭“多普勒与红移”将强行令 g ≡ 1（类似电影视觉对称效果）；关闭“引力透镜”将退化为平直欧几里得直线投影（半径 r_h 的黑球与平盘），二者均属非物理对比视图。
6. 测试粒子投影近似：3D 轨迹线叠加层按平直空间逆投影绘制，而粒子本体光球在物理视图中经过完整引力透镜光线追踪。
