关于这个模型

克尔时空 · 逐像素测地线 · 中文界面 · 单文件离线运行

画面中的每一个像素，都是从相机出射的一条光线在弯曲时空中用四阶龙格–库塔法逐步积分的结果。阴影、光子环、盘的远侧翻到黑洞上方、次级像、左右不对称的红移，全部是积分的自然结果，没有贴图，也没有手绘的光晕。

物理约定

  • 几何单位 G = c = 1，黑洞质量 M = 1；长度单位是 GM/c²，不是史瓦西半径 r_s = 2M。
  • 克尔自转 a = J/M，最大取 0.998；盘在赤道面内顺行转动，内缘在顺行 ISCO。
  • 盘温度用 Novikov–Thorne / Page–Thorne 通量剖面，内缘零力矩；观测温度 T_obs = g·T(r)，g 相对无穷远静止观察者。
  • 颜色取自 2.5 节的黑体色表（线性 sRGB，最大分量归一），亮度按 10^logY 给出；黑体经红移后仍是黑体。
  • 相机是静止观察者，使用局部标架起步；相机处的进一步蓝移用 1/√(1−f_cam) 并进盘温度。

必须说明的近似

  • 盘的峰值色温 T_max 是人为选择的显示参数。真实超大质量黑洞的薄盘峰值在紫外；银心和 M87 周围的气体更不是这种几何薄盘。
  • 渲染采用“冻结时间”近似：假设光线穿过场景的这段时间里盘与粒子没有移动，忽略光行时差。
  • 星空是程序化生成的，不是真实星图；银河带只是噪声。
  • 相机自身运动造成的光行差没有模拟；自动环绕时也没有。
  • 关闭“多普勒与红移”后令 g ≡ 1；关闭“引力透镜”后光线走直线，黑洞变成半径 r_h 的黑球。这两种状态都是非物理的，只用于对照。
  • 轨道实验室的粒子、轨迹与 S2 轨道是用平直空间针孔投影画在画面上的叠加层，没有经过引力透镜（见 BH.info.particlesLensed = false）。S2 的位置用开普勒根数计算，进动角用解析公式；二者的数值都在自检面板里。
  • 盘是零厚度、光学厚的几何薄盘；湍流纹理由两个错相 fbm 层生成，属于视觉模型，不是磁流体力学解。
  • “阴影角直径”用 2√27 r_g / D（a = 0）计算；克尔阴影不是圆形，实时数据里的视界、光子球与 ISCO 才随自转变化。
  • BH.trace 返回的 g 永远是物理值（相对无穷远），不受“多普勒与红移”开关影响；画面着色才受开关影响。

数值方法

  • 史瓦西：等价于 u″ + u = 3u² 的笛卡尔积分，h2 = |x×v|² 守恒；克尔：Kerr–Schild 笛卡尔坐标下的哈密顿形式，自转取 A = −a 正向追踪，避免视界附近的动量发散。
  • RK4，自适应步长 h = min(k·r, 0.5·max(r−r_h, 0.04))；盘用相邻两步 z 变号检测，r_hit = √(x²+y²−a²)。
  • 相机在 300 M 以外时从包围球解析起步/终止，使步数与相机距离无关，并保留 7.10 的横向分量修正。
  • 自检面板里的实测值全部由页面当场计算（GPU 光线追踪、CPU 双精度轨道积分或解析公式），不是写死的字符串。

自由发挥：引力波

  • 顶部的“引力波”面板对 GW150914（35.6 + 30.6 M☉）画出最低阶旋近啁啾波形与频率曲线，并把 f(τ=0.1 s)、35 Hz 对应的 τ 在源参考系与观测系两组参数下当场计算出来（44.0 Hz / 0.185 s 与 41.7 Hz / 0.160 s 附近），可拖动两个质量滑块看数字变化，并用 WebAudio 播放啁啾。
  • 它和主场景共用同一套太阳质量、引力常数与 GW150914 预设（r_g、t_g 的换算直接来自 BH.units），并给出无量纲的 Mcf 与 τ/Mc。这条公式只覆盖旋近阶段，不能外推到并合与铃宕；后者（约 150 Hz 峰值、约 250 Hz 铃宕）在面板里单独注明。

操作

  • 拖拽：改变极角 i 与方位角 φ；滚轮 / 双指：对数缩放相机距离（3 – 10⁶ M）。
  • 选择 Sgr A* 后，把相机拉远到约 10⁵ M 可以看到 S2 的轨道；右侧卡片有一键拉远按钮。
  • window.BH 是验收接口：set / get / trace / radii / disk / orbit / units / s2 / stats / selfCheck。

数据来源：GRAVITY 2020/2022、EHT 2019/2022、Miller-Jones et al. 2021、GWTC-1；常数与公式照任务规格书。
