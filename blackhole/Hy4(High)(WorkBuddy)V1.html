关于 · 模型与近似（诚实性说明）

这是真的
· 每个像素都是一条测地线：a = 0 走 §3.2 的史瓦西快速路径，a > 0 走 §3.3 的 Kerr–Schild 哈密顿形式，均为四阶龙格–库塔、自适应步长。
· 克尔情形把自转反向后正向追踪，避免视界处动量发散。
· 盘的内缘是当前自转下的顺行 ISCO；交点半径用 √(x²+y²−a²)；每次穿过赤道面用 z 变号检测，因此次级像、光子环是积分的自然结果。
· 红移 g 含引力红移与多普勒；黑体色表按观测温度 g·T 插值，亮度用 logY。
· 视界、光子圆轨道、ISCO、圆轨道周期、进动角、S2 轨道都按规格书公式计算。
这是近似 / 人为设定
· T_max 是人为选的显示参数。真实超大质量黑洞吸积盘峰值在紫外；银心与 M87 周围的气体甚至不是本模型这种几何薄、光学厚的盘。
· 采用冻结时间近似：算一帧时假设光线穿过场景期间盘与粒子没有动，忽略光行时差。
· 星空（恒星、银河带）与盘面湍流都是程序化噪声，不是真实星图或 MHD 模拟。
· 相机是静止观察者，没有模拟相机自身运动的光行差；相机处静止观察者的频率因子 1/√(1−f) 已乘进观测温度。
· 关闭「多普勒/红移」或「引力透镜」时画面是非物理的（前者是《星际穿越》的做法）。
· 测试粒子、轨迹、S2 轨道用平直空间投影画在叠加层，未经过透镜；Kerr–Schild 与 BL 方位角的差异被忽略（a = 0 时无此问题）。
· 盘温度用 §2.6 的 Novikov–Thorne 相对论剖面（diskModel = NT）；F_max 由 CPU 扫描求得。
· 「亮环直径」与「几何阴影直径」不是同一个观测量：EHT 看毫米波，气体也不是薄盘，两个数字接近不等于本模型就是那两个天体的样子。

拓展实验 · 全部数字由本页现算

① 热斑光变曲线
热斑画进主渲染管线（盘命中处叠加高斯亮斑）；曲线按同一个 Ω(r) 与 §3.5 的 g 计算。核对：光变周期 = 2π(r^1.5+a)。
② EHT 观测模式
用当前预设的角直径距离把 20 μas 换算成屏幕像素，走同一条后处理管线做高斯模糊。核对：2√27·r_g/D 与 EHT 实测亮环直径。
③ 引力波 / 跳进视界
啁啾公式 f(τ) = (1/π)(5/(256τ))^(3/8)(G M_c/c³)^(−5/8)，用 §2.1 的 t_g 换算。跳进视界：从视界到奇点的固有时上界 π·t_g。
