📖 物理模型、数值算法与诚实性近似说明

1. 时空测地线与几何单位制：本模型内部严格采用几何单位 G = c = M = 1（长度单位为引力半径 r_g = GM/c²，注意并非史瓦西半径 2M）。a = 0 时走球对称二阶常微分方程快速路径；a > 0 时在无极轴奇点的出射型 Kerr–Schild 笛卡尔坐标（令 A = −a 正向积分，彻底消除视界动量发散）下用四阶龙格–库塔（RK4）逐像素积分零测地线，BH.trace 与主画面共用同一段 GPU GLSL 积分函数（traceBackend: 'gpu'）。

2. 吸积盘色温标度人为设定说明：盘辐射通量径向分布严格采用相对论性 Novikov–Thorne / Page–Thorne (1974) 薄盘剖面（diskModel: 'NT'），但峰值显示色温 T_max（默认 7000 K）属于人为选取的可视化参数。真实的超大质量黑洞薄盘峰值往往落在极紫外波段，恒星级黑洞落在软 X 射线波段；而银心 Sgr A* 与 M87* 周围实际是光学薄、几何厚的辐射低效吸积流（RIAF）毫米波同步辐射，并非本模型的光学厚几何薄盘。

3. 冻结时间近似（Fast-Light Approximation）：渲染单帧画面时采用「冻结时间」近似，即假设光线穿过黑洞邻域的几十至上百 M 时间内，吸积盘湍流纹理、热斑与测试粒子位置保持静止，忽略不同光路之间的光行时差（Shapiro 时间延迟对动态纹理相位的偏移）。

4. 观察者标架与频移约定：标准模式下的相机为位于坐标半径 Rc 处的当地静止观察者（Static Observer），已严格计入当地正交标架与坐标基矢的径向变换，但未模拟相机自身轨道环绕速度带来的狭义相对论光行差（仅在「跳进视界」自由落体实验舱中专门开启下落观察者光行差）。红移因子 g = ν_obs / ν_em 按规范相对无穷远静止观察者定义；位于有限距离 Rc 的静止相机还会额外感受到微小的统一引力蓝移因子 1/√(1 − f_cam)（Rc = 30 时约为 1.035，视觉上等价于将人为参数 T_max 微调 3.5%，故着色器直接采用相对无穷远的 g 以保持与验收表一致）。

5. 程序化背景与粒子叠加：背景恒星与银河尘埃带由方向空间三维哈希与分形布朗运动（fBm）程序化实时生成，并非真实天球星表。有质量测试粒子的发光核心已在光线追踪循环内做最近距离高斯积分（particlesLensed: true，转至黑洞背后会自动形成引力透镜拉长像与爱因斯坦环），而辅助历史轨迹细线与 S2 星轨道椭圆则以平直空间透视投影叠加在 2D 画布层上（在 S2 所在的数千至数万 M 尺度上平直投影极其精确）。

6. 非物理对比开关标注：当关闭「多普勒与红移」（强制 g ≡ 1，类似电影《星际穿越》的艺术对称化处理）或关闭「引力透镜」（光线沿平直空间直线传播）时，画面仅供教学对比，属于非物理状态，界面顶部会自动亮起醒目的「非物理渲染模式」警示标志。
